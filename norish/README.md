# Norish add-on

Self-hosted [Norish](https://github.com/norish-recipes/norish) recipes for Home Assistant,
with its database, link imports and a nightly GitHub backup inside one add-on. It shows in
the sidebar as **Recipes**, a dashboard with Norish in one full-page frame. Setup:
[DOCS.md](DOCS.md).

Norish is AGPL-3.0. This add-on runs Norish's published image unchanged.
